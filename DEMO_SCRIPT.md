# Pull Guard demo script

1. Open the review queue and point out the focused task-board fixture.
2. Show the coherent feature PRs progressing from core domain to CLI.
3. Open the proposal cluster and compare the overlapping dashboard alternatives.
4. Choose the replacement proposal and mark the earlier approach superseded.

The fixture has no network or package-install requirements. Run
`python -m src.taskboard.cli --status doing` during the walkthrough.
